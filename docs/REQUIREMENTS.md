# THEDA E-Commerce — Requirement (คร่าว ๆ)

> ที่มา: โน้ตลายมือ 12 หน้า (LINE, 14 ต.ค. 2026) — โฟลเดอร์ `OneDrive/Desktop/theda`
> สถานะ: ร่าง requirement ก่อนถามลูกค้ายืนยัน

## 1. ภาพรวมโปรเจค

- บริษัท "ธีด้า" มีเว็บแบรนด์อยู่แล้ว (theda.co.th) ต้องการ **เว็บขายของ (E-commerce) เพิ่มอีกเว็บหนึ่ง**
- สินค้า ~20 รายการ
- ระบบหลัก 3 อย่าง: **สมาชิก / สั่งซื้อ / ชำระเงิน**
- งบประมาณ: เพดาน **~50,000 บาท**
- เวลา: **~3–4 สัปดาห์**
- ดีไซน์: สอดคล้องเว็บแบรนด์เดิม คงความ premium สีสันเพิ่มขึ้นได้ / ใช้โลโก้+ฟอนต์เดิม
- รองรับ Desktop + Mobile (responsive), **2 ภาษา ไทย/อังกฤษ**

## 3. ระบบสมาชิก

- สมัคร/เข้าสู่ระบบด้วย **เบอร์โทร (OTP)** หรือ **อีเมล + password (bcrypt)**
- **LINE Login (LIFF)** + เชื่อม LINE OA ของธีด้า
- ข้อมูล: ชื่อ ที่อยู่จัดส่ง เบอร์ อีเมล วันเกิด (รับส่วนลดวันเกิด ถ้ามี)
- ระดับสมาชิก Member/Silver/Gold (ตามยอดสะสม) — *ถ้ามี*

## 4. ระบบสั่งซื้อ

- ตะกร้า: เพิ่ม/ลบ/แก้จำนวน
- Checkout: ที่อยู่ → วิธีชำระ → ยืนยัน
- **Guest checkout ได้** (ต้องกรอกเบอร์โทรเพื่อติดตาม/แจ้งเตือน)
- ค่าส่ง: flat ตัวอย่าง 50 บาท, ฟรีเมื่อซื้อครบ 500 *(ตัวเลขต้องถามลูกค้า)*
- สถานะออเดอร์: รอชำระ → ชำระแล้ว รอจัดส่ง → จัดส่งแล้ว → เสร็จสิ้น
- แจ้งเตือนผ่าน LINE / SMS

## 5. ระบบชำระเงิน

1. **PromptPay QR** — สร้าง QR อัตโนมัติในหน้า checkout + เลขอ้างอิง (gen เองด้วย lib ไทย หรือ Omise)
2. **โอนธนาคาร** — แสดงบัญชี + แจ้งสลิป
3. **บัตรเครดิต/เดบิต** — ผ่าน **Omise หรือ 2C2P** (fee ~2.5–3.5%)
- ใบกำกับภาษี: ขอได้ในหน้าออเดอร์ (เลขผู้เสียภาษี + ที่อยู่)

## 6. ระบบแอดมิน

- Dashboard: ยอดขายวัน/สัปดาห์/เดือน + ออเดอร์ล่าสุด
- สินค้า: เพิ่ม/แก้/ลบ, สต็อก, รูปภาพ
- ออเดอร์: ดู, เปลี่ยนสถานะ, พิมพ์ใบจัดส่ง
- สมาชิก: ค้นหา, ประวัติซื้อ
- รายงาน: ยอดขายตามช่วงเวลา, สินค้าขายดี, สต็อกต่ำ
- Settings: ค่าส่ง, ส่วนลด, แอดมิน (role super/staff), log การแก้ราคา

## 7. Tech Stack (ที่โน้ตเสนอ — ตรงกับที่โปรเจคนี้ใช้อยู่แล้ว)

- Frontend: Next.js (App Router) + TypeScript + Tailwind, i18n TH/EN
- Backend: Next.js API routes (+ Drizzle ORM)
- DB: SQLite (dev) → **PostgreSQL** (Neon/Supabase) production
- Auth: OTP (SMS provider) / email+bcrypt / LINE LIFF
- Payment: PromptPay QR (lib ไทย/Omise), Omise/2C2P สำหรับบัตร

## 8. นอกขอบเขต (คิดเพิ่มถ้าลูกค้าขอ)

- ระดับสมาชิกแบบละเอียด, ระบบแต้ม/คูปองซับซ้อน, B2B RFQ แบบ alibaba, native app

2. ช่องทางชำระเงินอันไหนทำก่อน — โอน/PromptPay/บัตร?
3. Guest checkout ได้ไหม?
4. เว็บเดิมมีหน้า admin/ระบบหลังบ้านไหม — ทำ pattern เดิมไหม?
5. สี/ฟอนต์/โลโก้ ใช้ของเดิม หรือปรับเพิ่ม?
